# GVOexcel-AllSheet

在安瑟兒的 GVOexcel（大航海時代 Online 發現物統計表）裡自動加入一個「All」頁，把「史跡」到「天文」的所有發現物接成一張表。

## 用法

1. 安裝 [Python](https://www.python.org/downloads/)（安裝時勾選 *Add python.exe to PATH*）。不需要另外安裝套件。
2. 下載 `gvo_add_all_sheet.py` 和 `add_all_sheet.bat`，放在同一個資料夾。
3. 先把 GVOexcel 檔在 Excel 裡關掉，然後把它拖到 `add_all_sheet.bat` 上。
   也可以把 bat 放在 GVOexcel 檔的資料夾裡直接雙擊，它會找資料夾裡最新的 `GVOexcel*.xlsx`。

腳本會直接把「All」頁加進那個檔案，執行前先備份成 `檔名.bak.xlsx`。
安瑟兒出新版時，對新檔案再拖一次即可；檔案裡已經有 All 頁會整頁重建。

## All 頁有什麼

- **所有發現物一張表**，格式和「史跡」頁相同，可以用表頭篩選。例如到了卡利卡特，在「接任地點」打「卡利卡特」。
- **þ、2～5 五個角色欄是公式**，自動帶出各分類頁的打勾。打勾照舊在各分類頁做，All 頁只負責顯示。這五欄有鎖定，避免不小心改到。
- **前置發現自動判斷**：在黃色的 C1 格選角色（1～5），前置發現會依該角色的狀態上色：綠色＝已完成，紅色＝未完成。
- **「可接」欄**：✔＝還沒做而且前置都完成了；?＝有前置無法判斷（多半是不產生發現物的任務），請自行確認。
- 任務欄的超連結、註解、接任地點的顏色都會帶過來。

## 注意

- 不要在 All 頁的打勾欄直接打勾，請到各分類頁打。
- All 頁有開工作表保護（沒有密碼）。要排序時先到「校閱 → 取消保護工作表」。
- 支援 Excel、OnlyOffice 存的檔案。
- 前置發現欄有些是原表的筆誤，腳本會做近似比對，執行時會列出清單。配錯的話，把名稱加進腳本開頭的 `NO_FUZZY`；抓不到的筆誤可以加進 `ALIAS_MAP`。
